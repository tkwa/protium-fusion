# Prescribed pulse profiles

This directory retains the initial profiles and related numerical records used by the spherical pulse and component calculations. The 30 m reference radius is a scale parameter, not the outer radius of the incoming or compressed material. Each profile specifies radial positions, density, temperature and velocity; these are inputs to the model, not a demonstrated driver.

The retained records preserve original results and source hashes. Some describe superseded solvers or incomplete integrations; compare their status and input metadata before using them. The corrected pulse solver and its regression are documented in [b2-completion](../../b2-completion/NUMERICAL-COMPLETION.md). The current mixture calculations use the initial profile data in this directory.

These files originally appeared under a historical path; recorded path strings and hashes identify their original source and were not rewritten. The original snapshot is available in [v0.1](https://github.com/tkwa/protium-fusion/tree/v0.1/docs/protium-fusion/reassessment-2049/small-stages).
